# Roadmap

## v1.0.0

This maintains the historical API but allows for composer autoloading.

- [x] Composer support.
- [x] PSR2 bar class names.
- [x] Migrate tests to PHPUnit.


## v2.0.0

The historical API will be broken by classname changes.

- [x] Introduce namespacing.
- [x] PSR4 autoloading.
- [x] Automated testing.
- [x] PHP 5.4 minimum.

## v3.0.0

- [x] PHP 7.2 minimum.
- [x] PHPUnit 8.
- [x] Enable strict typing mode for all PHP files.

## v4.0.0

- [x] PHP 8.1 minimum.
- [x] Full parameter, return and property type declarations.
- [x] PHPUnit 10/11/12.
- [x] PSR-12 coding standard.
- [x] Static analysis with PHPStan.
- [x] GitHub Actions CI (replacing Travis CI).
